### 📌 Loyiha Haqida (Overview)

**Study Hub** — bu dasturchilar va talabalar uchun o'quv jarayonini rejalashtirish, kunlik vaqtni monitoring qilish va o'quv intensivligini (streak) oshirishga mo'ljallangan interaktiv web-ilova. 

Loyiha **Dark Glassmorphism UI** uslubida ishlab chiqilgan bo'lib, foydalanuvchiga qulay va zamonaviy interfeys taqdim etadi.

---

### ✨ Asosiy Imkoniyatlar (Key Features)

- 🔥 **Streak Tracker (O'quv Intensivligi):** Har kunlik uzluksiz o'rganish kunlarini hisoblab boruvchi gamifikatsiya tizimi.
- ⏱️ **Kunlik Maqsad & Pomodoro Taymer:** O'quv sessiyalarini boshlash va vaqtni jonli monitoring qilish.
- 📊 **Statistika va Analitika:** Bajarilgan vazifalar, sarflangan soatlar va loyihalar dinamik ko'rsatkichlari.
- 🎯 **Yo'nalishlar Moduli:** Full-Stack Dev, Sun'iy Intellekt, Ma'lumotlar Bazasi va Chet tillarini o'rganish modullari.
- 🔔 **Interactive Toast Notifications:** Barcha harakatlar va menyu almashinuvlari uchun qulay bildirishnomalar.

---

### 🛠️ Texnologiyalar Steki (Tech Stack)

- **Frontend:** HTML5, CSS3 (Custom CSS Variables, Flexbox, Grid, Glassmorphism UI), Vanilla JavaScript (ES6+ / Async DOM)
- **Icons & Design:** FontAwesome 6, Google Fonts
- **Backend (Rejalashtirilgan):** Node.js, Express.js, SQLite / PostgreSQL
- **AI Integration (Kelgusida):** Gemini API / GPT API (AI Asistent moduli uchun)
- **Deployment:** Render / GitHub Pages
